# Scripts des vidéos de référence

Textes reconstitués à partir des sous-titres incrustés (OCR toutes les 0,25 s, puis relecture).
Les mots entre `[crochets]` n'étaient pas lisibles et sont déduits du contexte.
Les timecodes sont approximatifs (± 0,3 s). Données brutes : `ocr/*.json`.
