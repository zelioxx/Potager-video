## Voix, polices, sons
- **Voix off** : générée localement avec le modèle Piper « fr_FR-tom-medium » (voix masculine), jeu de données « French-tts-model-piper » de Tjiho (AGPLv3), exécuté avec sherpa-onnx ; intonation élargie avec Praat (parselmouth) pour un débit plus vivant.
- **Musique de fond** (`music.wav`) : composée et synthétisée pour ce projet (`build/music.py`), libre de droits.
- **Polices** : Lilita One et Fredoka (via Fontsource), SIL Open Font License 1.1.
- **Effets sonores** (`pop`, `whoosh-short`, `click-soft`, `sparkle`, `chime`) : Pixabay, Pixabay Content License (fournis avec le skill HyperFrames media-use).
- **Icônes** (soleil, nuage, gouttes, flocons, coche, croix, panneau) : dessinées en SVG directement dans la composition.
- **GSAP** 3.12.5 : licence standard GreenSock.
